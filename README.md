# Семейное меню

Статический сайт с рецептами, списком покупок и планом готовок. Дизайн и работа сайта живут в `src/`, данные текущей недели — отдельно в `src/data/weeks/`.

## Обновление недели

1. Скопируйте `src/data/weeks/2026-10-19.js` и назовите новый файл датой понедельника, например `2026-10-26.js`.
2. Обновите объект `week`, дни `days`, готовки `sessions` и календарный файл в `src/calendar/`.
3. В `src/data/weeks/current.js` замените одну строку экспорта на новый файл.
4. При необходимости добавьте рецепт в `src/data/recipes.js` и его фотографию в `src/images/`.
5. Запустите `npm run check` и `npm run build`.

После отправки изменений в ветку `main` GitHub Actions проверит меню и опубликует его в Cloudflare Workers.

## Однократная настройка публикации

1. Создайте пустой репозиторий GitHub и загрузите в него этот проект.
2. В Cloudflare создайте API-токен с правом редактирования Workers и добавьте в Secrets репозитория `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.
3. При необходимости поменяйте название Worker в `wrangler.jsonc`. Первое успешное действие GitHub создаст адрес `*.workers.dev`.

Автоматическая публикация включена. Само содержание следующего меню требует проверенного источника данных: проект не будет самовольно придумывать рацион или менять медицински важные рекомендации.
